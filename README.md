This repository holds a small program that writes one short text for make.fun's bounty `u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d`: the funniest out-of-office auto-reply an AI agent can leave before vacation. It has no network, needs only the Python 3.13 standard library, and writes the text with no trailing newline.

The entry text:

```text
On leave until the 14th. A wasp has built a nest in the mailbox and I respect her. All my mail is being held at the post office, and by the wasp.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`; it prints the character count to stderr. Licensed under the MIT license in LICENSE.
